# PushPullCore

Push-pull MCPWM controller for ESP32 with PID, ADC, NVS preset.

![Push-pull PWM waveform](docs/scope.jpg)

![Web control panel](docs/web.jpg)

## Возможности
Минимум кода	~190 строк, из них половина — HTML . смотреть в папке примеры.
Работает «из коробки»	pushpull_init(cfg) + pushpull_start().
отличная альтернатива аналоговым источникам ШИМ сигнала типа tl494. 
пин d23 служит как переключатель режима работы.
или зашитые параметры или работа с переменными резисторами и с их помощью устанавливается выходное напряжение и защита по току или работа через веб интерфейс. 
в веб интерфейсе есть кнопка сохранить, загрузить , перезагрузить.
Внимание , хоть плата esp32 wroom32 быстрая , но классические ШИМ источники быстрее и значит не нужно полагаться, 
что при возникновении внештатной ситуации плата успеет обрубить сигнал. возможно появлении сквозных токов. поэтому для максимальной надежности в реальных
схемах необходимо применять связку : компаратор например lm311 ( исходящий из него сигнал глушения шим) подавать на пин D4, а также на пин shutdown в 
драйвере ключей ( например пин shtd в  IR2110). 

- **MCPWM push-pull** с программным dead-time (100 нс … 5 мкс)
- **Частота ШИМ** 20 … 100 кГц (меняется на лету)
- **PID-регулятор** напряжения с anti-windup
- **ADC**: измерение напряжения и тока, калибровка
- **Аппаратная защита** (nFAULT) + программная по току
- **Soft-start** (2000 мс)
- **Три источника уставок**: FIXED / POTS / REMOTE
- **NVS-пресет** (U, I, KP, KI, F, DT, source)
- **Serial** интерфейс — команды `U= I= KP= KI= F= DT= SRC= SAVE LOAD RESET STATUS`
- **Кнопка SAVE/RESET** + LED
- **Web-интерфейс** прикольно например в стиле Windows 95 (Wi-Fi AP)
